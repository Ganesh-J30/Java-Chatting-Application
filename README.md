# 💬 Java Client-Server Chat Application

A simple **client-server chatting application built using Java Socket Programming and Multithreading**.

This project demonstrates how two Java programs can communicate with each other over a TCP connection. The server waits for a client connection, and once connected, both the client and server can send and receive messages simultaneously.

## 🚀 Features

- Client-server communication using TCP sockets
- Two-way messaging
- Multithreading for simultaneous reading and writing
- Graceful chat termination using `exit`
- Proper socket and server resource cleanup
- Console-based communication

## 🛠️ Technologies Used

- **Java**
- **Socket Programming**
- **TCP/IP**
- **Multithreading**
- **Java I/O Streams**
- **Git & GitHub**
